## 実装手順

1. `faq-data.js`: `qa.md` を日本語に翻訳し、カテゴリ定義(general / usage / advanced / troubleshooting)と全17問を `{ id, category, question, answer(HTML文字列) }` 形式で定義する。コード・固有名詞は原文のままにする。
2. `index.html`: 骨格を作成する。
   * `<header>`: h1「IBM Bob よくある質問」と説明文
   * 検索 `<input type="search">` と `<label>`
   * `<div role="tablist">` (タブはJSで生成)
   * 件数表示 `<p aria-live="polite">`
   * 一覧コンテナ、0件メッセージ、`<footer>`
3. `styles.css`: 変数(色、余白)を定義し、各コンポーネントとレスポンシブ(スマホでタブ横スクロール、最小320px)を実装する。`:focus-visible`、`prefers-reduced-motion` に対応する。
4. `app.js`: 状態 `{ category, query }` から絞り込み・描画する。
   * 絞り込み: カテゴリ AND (質問+回答テキストの小文字化部分一致)。回答テキストは初期化時に一度だけタグ除去して保持する。
   * アコーディオン: `button[aria-expanded][aria-controls]` と回答領域の `hidden` 切替。再描画しても開閉状態を維持するため、開いている項目のidを `Set` で保持する。
   * タブ: `role="tab"`、`aria-selected`、`tabindex` のロービング、左右矢印・Home/End対応。
   * 件数「N件のFAQ」と0件メッセージの更新。
5. 手動検証(検証計画)を実施し、問題があれば修正する。

## GUI実装

* 対象コンポーネント:
  * ヘッダー、検索ボックス、カテゴリタブ、件数表示、FAQ項目(アコーディオン)、0件メッセージ、フッター。すべて素のHTML要素で `index.html` と `app.js` が担当する。
* スタイル: `styles.css` に集約する。アクセント色 `#0f62fe`、本文 `#161616` 系、背景 `#ffffff` / `#f4f4f4`。日本語システムフォントスタック(外部フォントなし)。
* 状態管理: `app.js` 内のモジュール内変数 `{ category, query, openIds }`。変更時に `render()` を呼ぶ。
* 画面遷移: なし(単一ページ)。
* レスポンシブ対応: 最大幅約800pxの中央寄せ1カラム。メディアクエリでスマホ幅の余白・フォントを調整し、タブは `overflow-x: auto` とする。320pxまで崩れない。

## 検証計画

1. `node --check faq-data.js` と `node --check app.js` で構文確認(`node` が使えない場合はブラウザコンソールで確認)
2. `qa.md` の `###` 見出し数(17)と `FAQ_DATA` の件数を照合する(`grep -c '^### ' qa.md`)
3. ブラウザで `index.html` を `file://` で開き手動確認する。
   * 初期表示: 全17件、全閉
   * 各タブの件数: 一般5、使い方8、高度な機能2、トラブルシューティング2
   * 検索: 「MCP」、「コマンド」、該当なしの語、タブとの併用、空白のみ
   * アコーディオンの開閉(複数同時、再描画後の維持)
   * 幅 320 / 768 / 1280px
   * キーボードのみ(Tab、Enter、Space、矢印、Home/End)
   * 外部通信なし(外部URL参照がないことを `grep` で確認)
4. 仕様書の完了条件と照合する。
